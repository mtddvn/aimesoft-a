AimeCard : Universal OCR platform

 

AimeCard is a universal OCR platform for optical character recognition in the Aimenicorn software ecosystem. AimeCard can recognize both printed characters and hand-written characters with high accuracy (character level accuracy is more than 99%).  The most important feature of AimeCard Universal OCR is that, it allows users to create the templates for information extraction from the input images. AimeCard therefore can analyze structures in documents, extract tables, figures and can be customized to work with various types of documents such as passport, ID card, driving license, etc.

AimeCard Features

  • Allow users to config templates themselves
  • Driving license and passport recognition
  • Invoices and documents recognition

AimeCard Technologies

Aimesoft’s technologies to realize AimeCard

  • Computer Vision technologies
    Object recognition, semantic segmentation, face recognition, gender/age recognition, OCR (optical character recognition), image search/retrieval, predictive analytics based on image
  • Natural Language Processing technologies
    Tokenization, POS tagging, keyword extraction, synonym/antonym detection, information extraction, relation extraction, semantic search, natural language understanding
  • Layout understanding
    AimeCard Universal OCR algorithm automatically detects similar records in an image document, and extracts information based on template settings. 
  • Data Mining technologies
    Big Data processing, KPI prediction, predictive analytics based on Big Data, recomendation algorithms, data generation for machine learning
